# Security policy

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use the repository's
[private vulnerability reporting form](https://github.com/bwmp-dev/provenance-runner/security/advisories/new)
so maintainers can investigate and coordinate a fix before disclosure.

Include the affected version or commit, reproduction steps, impact, and any
known mitigations. Reports and follow-up should remain in the private advisory
until the maintainers confirm that public disclosure is appropriate.
