# Security policy

## Reporting a vulnerability

Report vulnerabilities affecting this repository through Provenance's shared
[private security reporting form](https://github.com/bwmp-dev/provenance/security/advisories/new)
in the main `bwmp-dev/provenance` repository. The form accepts reports for all
Provenance components, including private repositories. Reports submitted there
are private; do not put vulnerability details in issues, pull requests, commit
messages, or branch names in this repository.

Include the affected component and version or commit, reproduction steps,
observed impact, and any known mitigation. Do not include live credentials,
customer data, or unrelated confidential material. Keep follow-up in the private
advisory until maintainers coordinate disclosure.

The Provenance security/incident owner (the main repository administrator)
receives and triages reports. The initial response target is two business days;
suspected sandbox escape, cross-tenant exposure, credential compromise, or
publication compromise is escalated immediately when received.

The [shared security policy](https://github.com/bwmp-dev/provenance/blob/main/SECURITY.md)
defines fix coordination and disclosure. Private source and unpublished
vulnerability details remain confidential.
